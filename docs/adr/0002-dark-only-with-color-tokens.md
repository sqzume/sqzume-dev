# ダークテーマ一本で作り、色は CSS カスタムプロパティで定義する

このサイトはダークテーマのみを提供し、ライトテーマもテーマ切替トグルも持たない。
ただし色は最初からすべて CSS カスタムプロパティ (トークン) として定義し、
将来ライトテーマを足す場合に「トークンの値を差し替えるだけ」で済む状態を保つ。
デザインが固まっていない段階で 2 つのテーマを並行して決めるのは、
どちらも完成させられない最も確実な方法であるため。

## Considered Options

- **ライト/ダークのトグルを提供する**: 読者が選べる利点はあるが、全コンポーネントを 2 色で
  目視確認し続ける手間と、リロード時に反対のテーマが一瞬見える問題 (FOUC) を防ぐ
  インラインスクリプトが必要になる。
- **ホームを白基調、ブログを黒基調にする** (棄却): 却下した理由を明示的に残す。
  (1) ページ遷移のたびに明暗順応が起き、暗→明の切替は眩しさと残像として体感される。
  しかもこのサイトで最も使われる動線が「ホーム → ブログ」であり、一番通る経路に
  一番大きな不快を置くことになる。(2) 色トークンが 2 セットになり、トグル案と同じコストを
  払うのに「読者が選べる」という見返りだけがない。(3) ホームで作った印象がブログで切れ、
  奇抜なホームを作る目的そのものを損なう。

## Consequences

- 画面内の明度差は「サーフェス階層」(暗い背景の上に一段明るい面を重ねる) と
  「アクセント色」(触れる場所だけを光らせる高輝度色 1 色) の 2 つで表現する。
  ページ間でテーマを切り替えることでは表現しない。
- 「ホームだけ白くしたい」という案は一度検討して棄却済みである。再提案の際はこの記録を読むこと。
